1er question :
les etapes de creations sont : 
    D'abord executer la commande : npm create vite@latest 001 -- --template react
    Ensuite aller dans le dossier avec cd 001 puis lancer le serveur avec npm run 


*Les dossiers*

 src/ : Contient le code de l’application React
 
 node_modules/ : Contient les bibliothèques nécessaires au projet, comme React et Vite

 public/ : Contient les fichiers statiques, comme les images et les icônes




 *Les fichiers*

 index.html : C’est le fichier HTML principal où React affiche l’application

 src/main.jsx : Permet de démarrer React et d’afficher le composant principal

 src/App.jsx : Contient le composant principal de l’application et son interface

 package.json : Contient les informations du projet, les dépendances et les commandes d’exécution

 src/App.css : Contient les styles du composant App.

 src/index.css : Contient les styles généraux de l’application

 vite.config.js : Permet de configurer Vite

 README.md : Présente le projet et explique comment l’utiliser
 
 package-lock.json : Enregistre les versions précises des bibliothèques installées
